# DiaBAD

Android-приложение для мониторинга глюкозы и звукового оповещения при гипогликемии.

Целевое устройство: **Samsung Galaxy S25 Ultra** (Android 15 / API 35).  
Часы: **Galaxy Watch Ultra** (Wear OS) — тревога как системный будильник.  
Источник данных: **OtTai M8** (Share with AAPS).  
Единицы: **ммоль/л**. Интерфейс: **русский**.

## Продуктовые решения

| Тема | Решение |
|------|---------|
| Потеря связи с OtTai | Настройка из 3 режимов: тихо / мягкое напоминание / как тревога |
| Порог гипо по умолчанию | 3.9 ммоль/л |
| Приближение к гипо | 4.3 ммоль/л: пуш + вибрация, без полной тревоги |
| Клинический гайд | кнопка на карточке сахара: зоны ADA, стрелка Dexcom, Δ |
| История графика | последние 24 часа |
| Пользователь v1 | один телефон (ваш S25 Ultra) + Galaxy Watch Ultra |

## Архитектура (техническая)

| Решение | Выбор |
|--------|--------|
| Модули | `:app`, `:wear`, `:core`, `:domain`, `:data` |
| DI | Hilt (телефон) |
| Статус-бар | Bitmap на лету (итерация Service) |
| Бренд | DiaBAD (`branding/app-icon.png`) |

## Итерации

1. **Core/Data** ✅ — модели, Room 24ч, настройки, приём OtTai broadcast  
2. **Service & Notifications** ✅ — FGS, Bitmap в статус-баре, карточка в шторке, автостарт  
3. **Logic & Alarms** ✅ — гипо-тревога как будильник (стоп/отложить), звуки, тест, DND  
4. **UI** ✅ — One UI / бренд DiaBAD, Колобок, клинический гайд, дельта, шутки 
5. **Galaxy Watch** ✅ — будильник-тревога + плитки/осложнения (цифра, стрелка, дельта, зона)
6. **Samsung lock screen** ✅ — мини-виджет под часами / рядом: цифра, стрелка, дельта

## Тревога

- Порог по умолчанию **3.9 ммоль/л**
- **Приближение к гипо** с **4.3 ммоль/л**: пуш + сильная вибрация, без полной тревоги
- Режим тревоги: звук или **только вибрация**
- Выпадающий список мелодий и паттерн вибрации (телефон + Galaxy Watch)
- **Стоп** / **Отложить** (5–30 мин) как будильник  
- Сигналы: сирена, мед. бип, будильник, 3 оригинальных «мультяшных» тона, свой файл  
- `USAGE_ALARM` + доступ к DND  
- **Телефон**: полный экран поверх блокировки, как будильник, **Стоп** / **Отложить**
- Кнопка **Запустить тестовую тревогу** — репетиция на телефоне и часах, даже если сахар в норме
- **Galaxy Watch Ultra**: полный экран как у системного будильника, **сильная вибрация без звука**, Стоп / Отложить синхронизируются с телефоном  

## Galaxy Watch — виджеты

**Плитки (Tiles)** в карусели:
| Плитка | Что показывает |
|--------|----------------|
| крупно | большая цифра + стрелка |
| цифра+стрелка | значение и тренд в ряд |
| подробно | цифра, стрелка, дельта, возраст |
| стрелка | крупный тренд |
| дельта | изменение между замерами |
| зона | Норма / Низкий / Высокий |

**Осложнения циферблата:** цифра, цифра+стрелка, только стрелка, дельта, возраст замера, шкала 2–16.

### Установка на часы

1. Установите DiaBAD на телефон (сборка включает wear APK).  
2. В **Galaxy Wearable → Уведомления** включите DiaBAD и «Включать экран».  
3. На часах: добавьте плитки DiaBAD и осложнения на циферблат.  
4. При sideload: `./gradlew :wear:installDebug` на подключённые часы.

## Экран блокировки Samsung

Список **Добавить виджеты** под часами — только приложения Samsung. Сторонние туда нельзя зарегистрировать.

Сахар под часы ставится через **Good Lock → LockStar** (виджет «Сахар» 2×1: цифра, стрелка, дельта).

1. В DiaBAD нажмите **Установить LockStar** (или **Открыть LockStar**, если уже стоит).  
2. Зажмите экран блокировки → **LockStar** → сторонние виджеты → DiaBAD **Сахар**.  
3. На рабочий стол — отдельная кнопка в настройках DiaBAD.

Это не Now Bar внизу экрана.

## Источник правды: ветка `main`

Рабочая версия живёт в **`main`**. Новые фичи и агенты должны ответвляться от актуального `main` после `git fetch`, а не от старых черновиков и не от устаревшего локального снапшота. Иначе снова пропадут гайд, пред-гипо, выпадающие списки, батарея и LockStar.

## Обновление из приложения

Кнопка **Обновить** в шапке DiaBAD смотрит GitHub Releases (тег `v39`, файл `DiaBAD.apk`) и ставит APK поверх текущей установки. Нужно разрешение «установка из этого источника». Данные и настройки не удаляются.

## Сборка

Откройте папку проекта в **Android Studio** (Ladybug+), дождитесь Gradle Sync, Run на S25 Ultra.

В OtTai: **Профиль → Ottai Hub → Share with AAPS → вкл.**

При первом запуске DiaBAD попросит уведомления и (по желанию) исключение из оптимизации батареи Samsung.
