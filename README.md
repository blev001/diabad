# DiaBAD

Android-приложение для мониторинга глюкозы и звукового оповещения при гипогликемии.

Целевое устройство: **Samsung Galaxy S25 Ultra** (Android 15 / API 35).  
Источник данных: **OtTai M8** (Share with AAPS).  
Единицы: **ммоль/л**. Интерфейс: **русский**.

## Продуктовые решения

| Тема | Решение |
|------|---------|
| Потеря связи с OtTai | Настройка из 3 режимов: тихо / мягкое напоминание / как тревога |
| Порог гипо по умолчанию | 3.9 ммоль/л |
| Приближение к гипо | 4.3 ммоль/л: пуш + вибрация, без полной тревоги |
| Клинический гайд | кнопка на карточке сахара: зоны ADA, стрелка Dexcom, Δ |
| История графика | последние 24 часа |
| Пользователь v1 | один телефон (ваш S25 Ultra) |

## Архитектура (техническая)

| Решение | Выбор |
|--------|--------|
| Модули | `:app`, `:wear`, `:core`, `:domain`, `:data` |
| DI | Hilt (телефон) |
| Статус-бар | Bitmap на лету (итерация Service) |
| Бренд | DiaBAD (`branding/app-icon.png`) |

## Итерации

1. **Core/Data** ✅ — модели, Room 24ч, настройки, приём OtTai broadcast  
2. **Service & Notifications** ✅ — FGS, Bitmap в статус-баре, карточка в шторке, автостарт  
3. **Logic & Alarms** ✅ — гипо-тревога как будильник (стоп/отложить), звуки, тест, DND  
4. **UI** ✅ — One UI / бренд DiaBAD, Колобок, клинический гайд, дельта, шутки 
6. **Samsung lock screen** ✅ — мини-виджет под часами / рядом: цифра, стрелка, дельта

## Тревога

- Порог по умолчанию **3.9 ммоль/л**
- **Приближение к гипо** с **4.3 ммоль/л**: пуш + сильная вибрация, без полной тревоги
- **Прогноз гипо** (вкл. по умолчанию): полная тревога, если тренд за 15 мин ведёт ниже порога за 20 мин — даже если сейчас ещё 4.7
- **Быстрое падение**: полная тревога при −0.17 ммоль/л·мин, даже в норме
- На полном экране написана **причина** (низкий / прогноз гипо / быстрое падение), а не всегда «Низкий сахар»
- Режим тревоги: звук или **только вибрация**
- Выпадающий список мелодий и паттерн вибрации (телефон)
- **Стоп** / **Отложить 15 / 30 / 60 мин** — слот глушит тревогу на всё выбранное время, даже если сахар низкий  
- Сигналы: сирена, мед. бип, будильник, 3 оригинальных «мультяшных» тона, свой файл  
- `USAGE_ALARM` + доступ к DND  
- **Телефон**: полный экран поверх блокировки, как будильник, **Стоп** и слоты 15 / 30 / 60  
- Кнопка **Запустить тестовую тревогу** — репетиция на телефоне, даже если сахар в норме

## Экран блокировки Samsung

Список **Добавить виджеты** под часами — только приложения Samsung. Сторонние туда нельзя зарегистрировать.

Сахар под часы ставится через **Good Lock → LockStar** (виджет «Сахар» 2×1: цифра, стрелка, дельта).

1. В DiaBAD нажмите **Установить LockStar** (или **Открыть LockStar**, если уже стоит).  
2. Зажмите экран блокировки → **LockStar** → сторонние виджеты → DiaBAD **Сахар**.  
3. На рабочий стол — отдельная кнопка в настройках DiaBAD.

Это не Now Bar внизу экрана.

## Источник правды: ветка `main`

Рабочая версия живёт в **`main`**. Новые фичи и агенты должны ответвляться от актуального `main` после `git fetch`, а не от старых черновиков и не от устаревшего локального снапшота. Иначе снова пропадут гайд, пред-гипо, выпадающие списки, батарея и LockStar.

## Обновление из приложения

Кнопка **Обновить** в шапке DiaBAD смотрит GitHub Releases (тег `v48`, файл `DiaBAD.apk`) и ставит APK поверх текущей установки. Нужно разрешение «установка из этого источника». Данные и настройки не удаляются.

## Сборка

Откройте папку проекта в **Android Studio** (Ladybug+), дождитесь Gradle Sync, Run на S25 Ultra.

В OtTai: **Профиль → Ottai Hub → Share with AAPS → вкл.**

При первом запуске DiaBAD попросит уведомления и (по желанию) исключение из оптимизации батареи Samsung.

## Версия 0.8.0 — экспериментальный экран Android Auto

Добавлен экран Car App Library: сахар в ммоль/л, стрелка, время измерения,
возраст данных и статус по порогам из настроек. При потере свежих данных стрелка
скрывается, последнее измерение явно помечается. Экран читает общую базу OtTai,
обновляется при новых измерениях и каждые 30 секунд, пока открыт.

**Ограничение:** это прототип для проверки через Desktop Head Unit, а не
подтверждённая поддержка реального автомобиля. Категория IOT используется для
экспериментального экрана подключённого датчика; соответствие категории Google
Play не подтверждено. Категории мониторинга здоровья в Android Auto нет.
Для Car App Library установка APK из GitHub и «Неизвестные источники» не дают
доступа в реальной машине: требуется доверенная установка через Google Play
(например, Internal App Sharing / Internal Test Track). Публикация в Google Play
в этот релиз не входит; сначала требуется проверить допустимость категории.

Обновление телефона: кнопка **Обновить** → релиз `v46`, файл `DiaBAD.apk`.
Данные сохраняются при установке поверх версии с той же подписью.

Документация: https://developer.android.com/training/cars/testing


## Версия 0.8.1 — два способа Android Auto с музыкой

В настройках телефона добавлен раздел **Android Auto**:

1. **Карточки сахара в машине** — включаются отдельно (по умолчанию выключены).
   При подключении Android Auto приходят сообщения с сахаром, стрелкой, временем
   измерения и статусом. Карточка обновляется на новое измерение; при устаревании
   данных приходит одно предупреждение без стрелки. Минутный таймер не повторяет
   всплывающие сообщения. После отключения автомобиля карточка убирается.
   «Прочитано» и любой голосовой ответ только подтверждают карточку и не меняют
   тревоги или измерения. Ответы никуда не отправляются и не сохраняются.
   Включите в Android Auto режим разработчика → **Неизвестные источники**,
   **Уведомления сообщений** и **Показ первой строки**. Звук сообщений можно
   отключить. Кнопка **Проверить карточку сахара** работает при подключённом
   Android Auto, включённом режиме и наличии измерения. Данные видны пассажирам.
   Это экспериментальное использование формата сообщений; показ баннера и
   озвучивание определяются настройками Android Auto. Постоянного индикатора нет.

2. **Отдельный экран через KingInstaller** — кнопка **Скачать KingInstaller**
   открывает официальный GitHub автора. После установки нажмите
   **Передать DiaBAD в KingInstaller**, затем подтвердите установку APK поверх
   текущей версии. Передаётся копия установленного подписанного приложения,
   переустановка не требует удаления DiaBAD. Переподключите Android Auto,
   откройте **Настроить меню приложений** и проверьте наличие DiaBAD.
   Музыкальная сессия не создаётся, поэтому плеер остаётся у музыкального приложения.
   KingInstaller пытается изменить атрибуцию источника установки; на части устройств
   может требоваться Shizuku. Это сторонний обход, совместимость DiaBAD в машине
   не подтверждена. Официальное ограничение Google Play остаётся в силе.

Включите **Обновлять через KingInstaller**, чтобы кнопка **Обновить** передавала
следующие скачанные APK ему. Иначе стандартный установщик может сбросить атрибуцию.
Если KingInstaller удалён, отключите эту настройку для обычного обновления.
Оба варианта можно включать одновременно. Настраивайте их на стоянке.

Источники:
- https://developer.android.com/training/cars/communication/notification-messaging
- https://github.com/fcaronte/KingInstaller


## Версия 0.8.2 — наглядный экран и компактный виджет

Пользователь подтвердил работу версии 0.8.1 в автомобиле. Основной экран теперь
показывает крупный прибор с сахаром и стрелкой, цветную шкалу пользовательских
порогов и график за последние 3 часа. Разрывы связи не соединяются линией.
Рядом остаются текстовый статус, время измерения, возраст и изменение между
последними измерениями. При устаревании цифра серая, стрелка скрыта.

Добавлен отдельный адаптивный виджет **Сахар · Авто** с крупной цифрой,
стрелкой, статусом, возрастом данных и светлой/тёмной темами. Он обновляется
при новых данных и раз в минуту при работающем мониторинге. Доступен и в
обычном списке виджетов телефона.

**Маленькая область Android Auto:** если в настройках вашей версии Android Auto
есть выбор виджетов, добавьте DiaBAD → **Сахар · Авто**. Это отдельный виджет,
а не принудительное перемещение Car App Library в маленькую область.
В прежней панели Coolwalk назначение областей определяет Android Auto;
универсального переключателя для произвольного приложения нет. Наличие
новой панели виджетов и отображение в машине в этой версии не проверены.
Источник: https://developer.android.com/design/ui/mobile/guides/widgets/adapt

Обновление: **Обновить** → 0.8.2 (`v47` / `DiaBAD.apk`). Для сохранения
источника установки используйте включённый режим KingInstaller.
